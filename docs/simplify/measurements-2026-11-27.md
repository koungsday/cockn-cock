- 길이 = 문서 높이 ÷ 화면 높이. 누를 수 있는 것 = 본문 안 보이는 `a[href]·button·input·select·textarea·summary`(위 막대·하단 메뉴 7개 제외).
- 상자 = 본문 안 가로 100px·세로 40px 이상, 모서리 6px 이상, 테두리나 배경이 있는 요소. 중첩 = 다른 상자 안에 든 상자.
- 글자 크기·스타일·색 = 직접 글자를 가진 보이는 요소의 계산된 값(크기는 0.1px 단위).
- 색 면적 = 24×16px 격자 점마다 맨 위 요소에서 올라가며 처음 만나는 배경색(배경 그림은 "image"). 첫 화면 기준.
