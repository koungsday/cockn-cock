# 콕앤콕 데이터베이스

`001.sql`은 신규 콕앤콕 전용 PostgreSQL 프로젝트에 적용하는 초기 마이그레이션입니다. 운영 데이터를 넣지 않고 `club` 스키마에 모임, 회원, 회차별 명단, 응답, 출석, 공지, 반복 설정을 만듭니다.

- 회차별 명단에 포함된 회원만 응답과 출석을 기록할 수 있습니다. 회차와 회원 조합당 응답 한 건을 저장하며, 응답 변경 시 기존 행을 갱신합니다.
- 참석 의사와 실제 출석을 별도로 저장합니다. 명단에 응답 또는 출석 행이 없으면 각각 미응답, 미확인으로 표시할 수 있습니다.
- 모임과 공지에 무작위 공유 ID가 있습니다. 운영용 서버는 공개 링크로 조회할 수 있는 필드만 골라 응답하고, 관리 요청과 투표에는 로그인 사용자와 회원 정보를 확인해야 합니다.
- 일반 공개 역할과 Supabase의 `anon`, `authenticated` 역할에는 스키마와 테이블 권한을 주지 않습니다. 운영 API가 준비되면 전용 서버 역할에 필요한 권한만 부여합니다.

## 로컬 검증

저장소 루트에서 실행합니다.

```sh
npm --prefix database ci
npm --prefix database test
```

검증은 가상 레코드로 임시 PostgreSQL(PGlite)을 실행합니다. 클라우드 DB 주소나 키를 읽지 않습니다. 초기 마이그레이션 적용, 공개 역할 권한 차단, 명단 외 쓰기와 중복 응답 차단, 기존 응답 갱신, 실제 출석 분리, 일정 시각 제약을 확인합니다.
