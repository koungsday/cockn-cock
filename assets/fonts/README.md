# 콕콕콕! 웹폰트

- `NexenTire-Regular-2014.ttf`는 넥센타이어 주식회사가 배포한 Regular 원본입니다. 콕콕콕!의 제목 표시용으로 사용합니다. 서체 자체 판매와 제한된 용도에 관해서는 제작사의 사용 안내를 따릅니다. [제작사 안내](https://www.nexentire.com/kr/communication/download/font/index.php) · [웹 사용 범위 안내](https://www.sandollcloud.com/free-font/16533/NEXEN-TIRE-TTF)
- `WantedSansVariable-v1.0.3.woff2`는 원티드 산스 1.0.3의 공식 가변 웹폰트입니다. `WantedSansUI-v1.0.3.woff2`는 KS X 1001 한글 음절과 콕콕콕! 화면에서 쓰는 글자를 담은 경량 파일입니다. 두 파일에는 원티드 산스 프로젝트의 [SIL OFL 1.1](WantedSans-OFL.txt)이 적용됩니다. [원티드 산스 1.0.3](https://github.com/wanteddev/wanted-sans/releases/tag/v1.0.3)
